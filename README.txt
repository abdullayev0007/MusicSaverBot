MusicSaverBot - O'rnatish va ishga tushirish bo'yicha ko'rsatma

1. Fayllarni zip dan chiqarib oling.
2. insta_youtube_bot.py faylini oching va BOT_TOKEN o'rniga BotFather dan olgan tokeningizni yozing.
   Misol: BOT_TOKEN = "1234567890:ABCdefGhijkLMNOPQrstuvWXyz"
3. GitHub repository yarating va barcha fayllarni upload qiling.
4. Railway hisobingizga kiring (https://railway.app) va "New Project -> Deploy from GitHub Repo" tanlang.
5. Reponi tanlab, Start Commandga yozing:
   python insta_youtube_bot.py
6. Deploy tugmasini bosing.
7. Telegramda botni toping va /start yozing.
8. Bot tayyor! Endi YouTube link yuborsangiz MP3, Instagram link yuborsangiz video olasiz.
